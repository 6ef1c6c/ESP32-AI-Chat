本项目是为 ESP32-C6 开发板所制作的 AI 工具，未来可能支持更多的开发板。

## 🔗 实现

本工具无需依赖任何外设，正常构建情况下不会熔断任何 eFuse。<br>
通过连接 AP 热点访问 `192.168.4.1` 进行控制。<br>
默认热点密码为 `ESP123456`。<br>
默认情况下为 `AP + STA` 双模运行。<br>

关于分区：`NVS` 分区存放 API Key、Wi-Fi 密码等基础配置，`LittleFS` 分区存储聊天记录等文件。<br>
此工具为 API Key 调用来实现聊天功能，进入后台界面后，需进入设置连接网络，配置 API Key 才可正常使用。<br>

此工具的其他功能：<br>
RGB 指示灯（红，蓝，绿，渐变，关闭）。<br>
日志（共 4 个等级：`off`, `error`, `info`, `debug`）。<br>
开发板状态（包括 CPU 占用，内存占用，Flash 占用）。<br>

## 🔗 环境

框架 ESP-IDF 6.1
