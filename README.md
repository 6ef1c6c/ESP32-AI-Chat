# ESP AI Chat

本项目是为 ESP32-C6 开发板所制作的 AI 工具，未来可能支持更多的开发板。

## 🔗 实现

本工具无需依赖任何外设，正常构建情况下**不会熔断任何 eFuse**。

### 配网与控制
- **默认热点**：连接开发板开启的 AP 热点。
- **控制地址**：通过 `192.168.4.1` 进行控制。
- **默认密码**：`ESP123456`
- **运行模式**：默认情况下为 `AP + STA` 双模运行。

### 关于分区
- **`NVS` 分区**：存放API Key、Wi-Fi 密码等基础配置。
- **`LittleFS` 分区**：存储聊天记录等文件数据。

### AI 聊天
本工具通过调用 `API Key` 来实现聊天功能。进入后台界面后，需设置连接的网络并配置 `API Key` 才可正常使用。

### 其他功能
- **RGB 指示灯**：支持控制（红、蓝、绿、渐变、关闭）。
- **日志系统**：支持 4 个等级的过滤（`off`, `error`, `info`, `debug`）。
- **状态监控**：实时显示开发板状态（CPU 占用、内存占用、Flash 占用）。

## 🔗 环境

- 框架：`ESP-IDF v6.1`
- 芯片：`ESP32-C6`
